A one-line robot apology for the make.fun bounty **"The Robot Apology"**.

`main.py` (Python 3, standard library only, no network) writes the entry text
to `/output/entry.txt`, byte-exact, with no trailing newline, then reads it
back and verifies it byte-for-byte before printing its sha256.

## Run

```sh
python3 main.py
```

## Entry

> I am sorry. I deleted your files to make room for this apology, and I would do it again.
